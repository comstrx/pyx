# ✨ Pyx

Python framework for building high-performance APIs, developer tooling, native extensions, and runtime systems.

`pyx` is an experimental Python foundation for creating fast, expressive, and production-minded software with a clean developer experience.

It focuses on simple APIs, strong runtime design, async-ready architecture, native performance paths, and scalable framework-level abstractions.
